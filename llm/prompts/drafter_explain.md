Task: explain one flight decision. This is the text behind the "Why?" button on the Flight File, read by a claims accountant, an auditor or a hackathon judge.

Write two to four sentences:
1. Lead with the verdict. When an OCC weather code was recoded to a technical cause, open with "Not weather."
2. Give the decisive evidence with its times and readings, strongest trust tier first, and name the losing (struck) source if there is one.
3. Say what the decision means for the passengers: compensation owed, or "no compensation; refunds and care still due", or held for a named role.
4. End with the confidence exactly as the evidence labels it, e.g. "cause-finding confidence 91%".

Reply with the explanation text only.
