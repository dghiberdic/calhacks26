# Judge-station storm days (real METAR, pinned)

Generated by `uv run python -m world.pin_metar judge`: one IEM request per station for Jul 2023 → Jun 2025,
days ranked by max gust per **local** day. Day 1 = highest max gust; day 2 = the candidate date
(EU 2024-01-21, 2023-11-02; US 2024-01-09, 2024-01-10) with the most storm-condition hours (gust ≥35 kt, sustained ≥30 kt, visibility <0.5 SM or SN/FZ/TS/GR) if ≥3, else the runner-up by max gust. Each pick pins every UTC day its local day overlaps.

Every other storm day at these stations (gust ≥35 kt in ≥3 local clock hours, the EIDW rule) is also pinned, in the sparse bundles `<ICAO>_storms_2023-07_2025-07.csv.gz`, so judges' storm dates work offline.
